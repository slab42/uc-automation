# _logs Folder

Central repository for all log files generated by UC automation scripts.

## Purpose

- **Centralized logging** - All scripts write logs to this single folder
- **Easy monitoring** - All logs in one place for review and troubleshooting
- **Organized** - Timestamp-based filenames prevent collisions
- **Searchable** - All logs available for grep, analysis, and archival

## Log File Naming Conventions

Log files are automatically generated with timestamp-based names:

**CUBE/Router scripts:**
```
YYYY-MM-DD_HH-MM-SS-script_name.log
2026-09-16_10-55-22-check_router_status.log
2026-09-16_10-55-22-compare_router_config.log
```

**CUCM scripts:**
```
Script-Prefix-server_ip-YYYY_MM_DD-HH_MM_SS.log
Create-Region-Update-DevicePools-192.168.25.100-2026_09_16-10_54_16.log
Add-Advertised-Pattern-192.168.25.100-2026_09_16-10_54_16.log
```

**CUC scripts:**
```
Script-Prefix-cuc_server_ip-YYYY_MM_DD-HH_MM_SS.log
check-userMailbox-192.168.25.120-2026_09_16-10_54_16.log
cleanup-emptyMailboxes-192.168.25.120-2026_09_16-10_54_16.log
```

## Log File Contents

Each log file contains:
- Timestamp of operation
- Operation details (what was executed)
- Results (success/failure)
- Error messages (if any)
- Summary statistics

Log level: **DEBUG** (all operations logged)

## Viewing Logs

### List recent logs:
```bash
ls -ltr _logs/ | tail -10
```

### View specific log:
```bash
cat _logs/check_router_status-2026-09-16_10-55-22.log
```

### Search logs:
```bash
grep "ERROR" _logs/*.log
grep "192.168.25.100" _logs/*.log
```

### Follow live logs:
```bash
tail -f _logs/check_router_status-*.log
```

## Archival

Logs can accumulate over time. To archive old logs:

```bash
# Archive logs older than 30 days
find _logs/ -name "*.log" -mtime +30 -exec tar -rf logs_archive.tar {} \;
gzip logs_archive.tar

# Or simply compress and remove
find _logs/ -name "*.log" -mtime +30 -print0 | xargs -0 gzip
```

## Disk Usage

Monitor disk usage with:
```bash
du -sh _logs/
ls -lh _logs/ | tail -20
```

Clean up old logs if needed:
```bash
# Remove logs older than 60 days
find _logs/ -name "*.log" -mtime +60 -delete
```

## Git Ignore

The _logs folder is included in .gitignore to prevent log files from being committed:

```gitignore
# Logs
_logs/
_logs/*
```

This ensures:
- Log files never committed to git
- Sensitive information in logs stays local
- Repository remains clean
- Each user has their own log history

## Troubleshooting

### Logs not being written

If logs are not being created in _logs/:

1. Check directory exists and is writable:
   ```bash
   ls -ld _logs/
   touch _logs/test.log && rm _logs/test.log
   ```

2. Check script is using correct path:
   ```bash
   grep "_logs" script_name.py
   ```

3. Check for fallback behavior:
   - Some scripts fall back to script directory if _logs is not writable
   - Check script directory for logs: `ls script_directory/*.log`

4. Verify syntax:
   ```bash
   python3 -m py_compile script_name.py
   ```

### Log file permissions

If you cannot read log files created by other users:

```bash
# Check permissions
ls -l _logs/ | head -5

# Make readable (if owned by you)
chmod 644 _logs/*.log
```

## Log Retention Policy

Recommended log retention:
- **Keep actively**: Logs from current week (working logs)
- **Archive after**: 30 days (for troubleshooting recent issues)
- **Delete after**: 90 days (unless needed for compliance/audit)

Logs are space-efficient but can accumulate. Review monthly and archive as needed.
